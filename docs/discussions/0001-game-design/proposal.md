# ゲームデザイン提案

- Status: Proposed
- Date: 2026-06-20

この文書は、実装エージェントが参照できる形で、意図するゲームルールとコンテンツの構成を記述する。
完全なバランス仕様ではなく、所要時間、獲得量、成功率、効率差などの値は今後の調整に委ねる。

## 基本コンセプト

Idle Barquest は Rust 製の TUI 放置 RPG である。プレイヤーは `Target` と `Action` を選び、
プログレスバーの完了を待って、資源、クラフト品、発見などの成果を得る。

ゲームは、1人の Hero が森を探索するところから始まる。やがて村と冒険者ギルドを発展させ、
Adventurer、Villager、Smith、Farm、Livestock などの Target を増やし、複数の仕事を並行して進める。

## コアループ

1. プレイヤーが Target を選ぶ。
2. その Target が実行できる Action を選ぶ。
3. 時間のかかる進行タスクとして Action が始まる。
4. 完了時に、報酬、発見、資源の枯渇、必要な状態変更を解決する。
5. 新しい資源、施設、エリア、Target によって、追加の Action が解放されることがある。

短く反復できる作業と、長い遠征の両方をこのループで扱う。
単純な採集は短時間で安定していてよいが、具体的な安定性や効率は固定ルールではなくバランス調整事項とする。

## 基本概念

### Target

`Target` は Action を割り当てられる人物または施設である。
役割に応じた得意分野を持たせる想定だが、効率補正はまだ確定しない。

| Target | 役割 |
| --- | --- |
| Hero | 中心となるプレイヤーキャラクター。幅広い冒険 Action を実行できる。 |
| Adventurer | ギルドが管理する探索、討伐、ダンジョン向けの働き手。 |
| Villager | 採集や伐採など、村の基本作業を担う。 |
| Smith | 鉱物やモンスター素材から武器、防具、道具を作る。 |
| Adventurers' Guild | Adventurer の雇用、依頼、遠征支援を管理する。 |
| Farm | 時間経過で食料や植物素材を生産する村の施設。 |
| Livestock | 時間経過で食料や動物素材を生産する村の施設。 |

### Action

`Action` は Target に割り当てる時間制の仕事である。各 Action は次の要素を持ちうる。

- 必要な Target の種類または施設
- 必要な資源または装備
- 所要時間
- 完了報酬
- 発見確率
- 枯渇への影響
- 必要になった場合の失敗または部分成功ルール

初期の Action 候補は次のとおり。

| Action | 目的 |
| --- | --- |
| Forest exploration | 木材、薬草、モンスター素材を得て、エリアを発見する可能性を持つ。 |
| Monster hunting | モンスター素材、報酬、食用にできる可能性のある素材を得る。 |
| Fishing | 川や湖から食料源となる魚を得る。 |
| Animal hunting | 肉、皮、骨などの動物素材を得る。 |
| Dungeon expedition | 長時間の作業によって宝、希少素材、装備を得る。 |
| Logging | 森林資源から木材を得る。 |
| Farming | Farm で作物、食料、植物素材を生産する。 |
| Livestock work | Livestock から肉、皮、骨などを生産する。 |
| Armor crafting | 木材、鉱石、モンスター素材を消費して防具を作る。 |
| Enchantment | 希少または魔法素材を使って装備に特殊効果を加える。 |

### Resource

資源をゲーム上の用途で分類する。

| 資源グループ | 例 | 用途 |
| --- | --- | --- |
| Natural resources | Wood、Herb | 序盤の村の発展とクラフトに使う素材。 |
| Minerals | Iron Ore | 鍛冶、道具、装備、施設強化に使う。 |
| Food | Fish、Meat、Crop、食用モンスター素材 | 活動を維持し、長い Action の条件になりうる。 |
| Monster materials | Claw、Hide、Core、食用部位 | クラフト、付与、報酬、生存に使う。 |
| Equipment | Weapon、Armor、Tool | Target の能力を高め、より難しい仕事を解放する。 |

Food は主要なサバイバル資源とする。働き手の維持、長い遠征の開始、反復作業の継続に
消費する可能性がある。ただし、食料管理の厳しさは放置ゲームのテンポを損なわないよう調整する。

## エリアと枯渇

エリアは Action と資源の供給源である。

森と鉱山は有限のフィールド資源とし、枯渇後に自然回復しない。
これにより、新しいエリアの発見や、再生可能な村内生産の整備が必要になる。

ダンジョンは再生可能な冒険資源とする。攻略または枯渇してから一定時間後に回復し、再利用できる。
希少素材、宝、戦闘報酬を繰り返し得る主要な供給源にする。

資源の入手経路は進行に応じて変化させる。

- 序盤: 近隣の有限資源から採集する。
- 中盤: 新エリアを発見し、村内生産を解放する。
- 終盤: 再生するダンジョン、Farm、Livestock、未探索エリアを組み合わせて供給を維持する。

## サバイバル要素

高負荷なサバイバルシミュレーションにはせず、計画に適度な圧力を加える。
食料源は Fishing、Animal hunting、食用モンスター、Farm、Livestock とする。

特に長い仕事の計画に影響する程度には Food を重要にするが、放置進行が簡単に止まるほど厳しくしない。

## 進行の概要

### 序盤

Hero が森を探索して木材や素材を集め、最初の発展経路を発見する。
食料は主に Fishing と hunting から得る。木材で村の基礎機能を整え、Villager や Smith を解放する。

### 中盤

Adventurers' Guild により働き手を増やす。Adventurer は探索、モンスター討伐、ダンジョン遠征を担い、
Villager は資源採集を支える。森の探索から鉱山、ダンジョン、特別な採集場所を発見できるようにする。

村の発展によって Farm と Livestock を解放する。これらは再生可能な食料と一部素材を供給し、
有限の森や鉱山への依存を減らす。

### 終盤

鍛冶と Enchantment で装備を強化し、より強いモンスターや深いダンジョンに挑めるようにする。
森と鉱山の枯渇後は、再生するダンジョン、村内生産、新しく発見したエリアで供給を維持する。

希少なダンジョン素材を装備や施設の強化へ還流させ、効率を上げて高難度コンテンツを解放する。

## TUI への要求

TUI では次の状態を把握しやすくする。

- 利用可能な Target と現在の仕事
- 選択した Target が実行できる Action
- 実行中タスクのプログレスバー
- 残り時間または進行率
- 資源インベントリ
- 発見と完了結果
- エリアの枯渇または回復状態
- Food の所持量と必要条件

タスク完了時のログには、獲得資源、発見エリア、クラフトした装備、枯渇状態の変化、
ダンジョンの回復状態など、意味のある成果を表示する。

## バランス方針

次は固定ルールではなく方向性とする。

- Target は役割に応じた得意分野を持ちうる。
- Hero は柔軟だが、専門 Target より効率が低くてもよい。
- 単純な採集は短時間で安定していてよい。
- 探索やダンジョンは時間がかかる代わりに、発見や希少報酬を提供してよい。
- Food は特に長い Action で重要にするが、放置ループを圧迫しすぎない。

## 未決事項

- 各段階で同時実行できるタスク数はいくつか。
- Food は Action ごとか、Target の時間経過ごとか、長い遠征だけで消費するか。
- 枯渇した森や鉱山を利用不能なエリアとして表示し続けるか、Action の候補から除くか。
- ダンジョンの回復を実時間、tick、完了タスク数のどれに結びつけるか。
- どの報酬を確定、確率、または両方にするか。
