# 素材獲得と報酬抽選の議事録

- 日付: 2026-08-30
- 結果: 提案を作成する

## 議論した内容

初期の3つの Location で `Gather`、`Fish`、`Hunt` が完了した際に、場所と行動の組み合わせに応じた素材を獲得する。すべての行動の所要時間は10秒とし、既存の方針どおり完了後に自動反復はしない。

実装する素材は `Pebble`、`Twig`、`Grass`、`Vine`、`Small Fish`、`Seaweed Fragment`、`Small Fang`、`Awful Meat` の8種類とする。discovery に候補としてあった `Tiny Magic Stone` は入手経路がないため、今回は定義しない。

報酬表の確率は独立に複数判定するものではなく、合計100%の表から1つの結果を選ぶ排他的な抽選とする。すべての素材報酬量は1個である。沿岸の釣りの90%は暗黙の余りではなく、`Nothing` という明示的な抽選結果として扱う。

獲得した素材は core の `GameState` がインベントリとして累積する。ただし、現時点では合計を確認する UI は追加せず、Information Log に完了と抽選結果を1行で表示する。素材の消費先とセーブ機能も今回は扱わないため、所持数はプレイ中のみ保持され、ゲームを終了すると失われる。この限定された状態で、報酬抽選、インベントリの土台、獲得時の体感を先に確認する。

discussion 0002 の初期素材表は今回の内容で置き換える。一方、同文書の技術とクラフトは旧素材名や今回定義しない素材を参照している。それらを今回の実装要件には含めず、開発が進んだ段階で序盤の進行全体を棚卸しする。

## 確認した質問

1. discussion 0002 の初期素材表を置き換えるか、旧素材と併存させるか。
2. 素材をインベントリに累積し、合計はまだ表示せずに獲得結果だけを Information Log へ出すか。
3. 各報酬表の確率を、常に1結果だけを選ぶ排他的な抽選と解釈してよいか。
4. 自動反復のない10秒タスクに対し、90%で何も得られない釣りの厳しさは意図したものか。
5. 素材の英語表示名をどうするか。
6. 入手経路のない `Tiny Magic Stone` を将来用に定義するか。
7. discussion 0002 の技術・クラフトに残る旧素材参照を今回更新するか。
8. 完了と報酬を1行にまとめ、空振りの `Nothing` も明示するか。
9. 合計表示、消費先、セーブのない限定された完成状態を、今回の実装範囲として許容するか。

## 採用しなかった案

- discussion 0002 の旧素材と今回の素材を併存させる案は採用しなかった。同じ初期 Location に複数の矛盾する報酬表が残るため、今回の表で置き換える。
- `Tiny Magic Stone` を入手不能なまま先に定義する案は採用しなかった。実際の入手経路を検討する際に追加する。
- 釣りの空振りを減らす、報酬をまとめて長時間の行動にする、または自動反復を再導入する案は今回採用しなかった。90%の空振りを含む厳しさの体感を確認することが目的であり、discussion 0006 で自動反復を採用しなかった方針も維持する。
- 釣りの失敗確率を暗黙の余りとする案は採用しなかった。空振りも報酬表内の明示的な `Nothing` として検証・表示する。
- 完了通知と報酬通知を複数行に分ける案は採用しなかった。最小端末高では Information Log に3行しか表示できないため、1回の完了を1行にまとめる。

## 保留事項

- 所持素材の合計を確認する UI。
- セーブ・ロードによるインベントリの永続化。
- 素材の消費先、技術、クラフト、食料への加工。
- discussion 0002 を含む序盤進行の棚卸し。
- 戦闘、モンスター、経験値、レベル、素材の用途に基づくバランス調整。
