# ターミナル表示スタイル変更の提案

- Status: Proposed
- Date: 2026-08-29

## 目的

ゲームタイトルの固有性を強めるとともに、プログレスバー内で連続するハイフンの視覚的な密度を下げ、画面を読みやすくする。

## タイトル

現在の1行タイトル `IDLE BARQUEST` を、次の3行のASCIIアートへ置き換える。

```text
.@~\::::::::::::::::::::::::::::::/@~.
(  {        IDLE BARQUEST         }  )
'@~/::::::::::::::::::::::::::::::\~@'
```

各行は38文字とし、端末幅にかかわらず内容を伸縮させず、タイトル領域内で水平方向の中央に配置する。中央行には、原案の右側へ空白を1つ加えて上下行と幅を揃える。

タイトル領域の高さは1行から3行へ変更する。タイトル直下にある既存の全幅区切り線は削除し、ASCIIアートの下段をタイトルと進捗領域の視覚的な境界として使う。それ以外の領域間の区切り線は維持する。

## プログレスバー

未完了部分の `-` を空白へ置き換える。

```text
[===>   ] 50%
```

表示上の意味は次のとおりとする。

- `=` は完了済みの進捗を表す。
- `>` は現在の進行位置を表す。
- 空白は未完了部分を表す。
- 百分率は従来どおり角括弧の右側へ表示する。

したがって、開始時、進行中、完了時の表示はそれぞれ次の形になる。

```text
[       ]   0%
[===>   ]  50%
[=======] 100%
```

未完了部分の境界は角括弧で、正確な値は百分率で確認できるため、色に依存せず進捗を把握できる状態を維持する。

## 画面サイズと領域配分

最小対応端末サイズは `80x24` のまま変更しない。タイトルが2行増え、タイトル直下の区切り線が1行減るため、現行レイアウトと比較して情報ログ領域は差し引き1行狭くなる。この減少は、既存の最小端末サイズとの互換性を保つために許容する。

## 反映対象

実装時には、タイトルと画面領域の計算、プログレスバー生成処理、および対応する描画テストを変更する。また、現在の表示仕様を記述している設計文書は、実装後の現況と一致するよう更新する。
