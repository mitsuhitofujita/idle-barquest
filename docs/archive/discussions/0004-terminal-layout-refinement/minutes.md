# ターミナルレイアウト見直しの議事録

- 日付: 2026-08-29
- 結果: 提案を作成する

## 議論した内容

タイトル、プログレス、選択肢、情報ログ、グローバルメニューの垂直配置を見直した。新しい順序は、Title、Information Log、User Choices、Progress、Global Menu とする。

Title は現行の3行を維持する。Title 直下には区切り線を追加せず、1行の空白を設ける。この空白は Information Log の最初の1行として確保する。

Information Log の高さは最小4行とする。先頭1行を Title との間隔に使うため、最小端末で実際にログを表示するのは3行となる。ログは領域の下端に揃え、新しい情報が下に表示されるようにする。端末が24行より高い場合、追加分の行はすべて Information Log へ割り当てる。

User Choices は見出し1行と6件の選択肢を表示するため、7行固定とする。Progress は6行固定とする。端末の高さに応じてこれらの領域を伸縮させる高度な計算は将来の拡張とし、今回は導入しない。

最小対応端末は `80x24` のままとする。Title 3行、Information Log 4行、User Choices 7行、Progress 6行、Global Menu 1行と、領域間の区切り線3行で、合計24行となる。

## 確認した質問

1. Progress と Information Log の入れ替え後の領域順序と、Title 直下の空白行の扱い。
2. Progress と User Choices を固定高にするか、表示件数に応じて伸縮させるか。
3. 最小高を25行に変更する理由と、VT100 の表示行数。
4. User Choices の6行が領域全体の高さか、表示する選択肢数か。
5. Information Log の領域自体を削除するか、Title の下へ移動して維持するか。
6. 24行に収めるため、Title 下の空白を Information Log の4行に含めてよいか。
7. 端末が最小高より高い場合の追加行の割り当て先と、ログの垂直方向の配置。

## 採用しなかった案

- 最小対応端末を `80x25` に引き上げる案は採用しなかった。VT100 の表示は80列24行であり、25行目はスクロールに使う内部バッファで通常は表示されないため、従来の `80x24` を維持する。
- Title 下の空白1行と Information Log 4行を別々に確保する案は、他の固定領域と合わせると25行必要になるため採用しなかった。空白行を Information Log の先頭行に含める。
- Information Log を削除する案は採用しなかった。領域は Title 直下へ移動し、Action 完了などの通知を表示する役割を維持する。
- Progress と User Choices の高さを端末やコンテンツに応じて今回から可変にする案は、今回の微調整の範囲を超えるため見送った。固定高で表示できる件数を超えるコンテンツを追加する前に、高度な高さ計算を導入する。
